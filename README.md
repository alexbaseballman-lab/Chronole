# Chronole

A daily geography-guessing game in the spirit of [Globle](https://globle-game.com/) — instead of
today's randomly chosen country, you're given a **year** from history and have to guess who held
the highlighted territory then.

## Stack

- React 19 + Vite, plain CSS (design tokens in `src/index.css`)
- [react-globe.gl](https://github.com/vasturiano/react-globe.gl) for the 3D globe
- Fully static — no backend. The daily puzzle is a date-seeded deterministic pick from a curated
  pool, so it's the same for everyone without a server.
- Historical boundary data from [aourednik/historical-basemaps](https://github.com/aourednik/historical-basemaps)
  (GPL-3.0) — see [DATA_SOURCES.md](./DATA_SOURCES.md).

## Development

```bash
npm install
npm run dev
```

## Data pipeline

`public/data/` is generated by `scripts/build-data.mjs`, which downloads a pinned commit of the
source GeoJSON, drops non-political features, merges same-named fragments (e.g. islands/exclaves)
into one entity per year, simplifies geometry, and computes centroids + land-area-weighted
puzzle-answer eligibility. It's a manual/occasional step, not part of `npm run build`:

```bash
node scripts/build-data.mjs
```

## Project structure

- `src/pages/` — routed pages: `Landing`, `HowToPlay`, `Play` (daily), `Practice`, `About`, `Privacy`
- `src/components/` — `Globe`, `GuessInput` (autocomplete), `GuessList`, `HintPanel`, `ShareResult`, `AdSlot`
- `src/hooks/useGame.js` — shared guess/scoring/persistence logic for daily + practice modes
- `src/lib/` — `geo.js` (haversine + color scale), `puzzle.js` (daily/practice selection),
  `gameState.js` (localStorage), `scoring.js` (share-grid text), `dataClient.js` (fetch layer)
